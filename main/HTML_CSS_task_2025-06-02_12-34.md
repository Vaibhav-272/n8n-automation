# Diving into the World of HTML and CSS: Your First Steps

## What is HTML?

HTML, or HyperText Markup Language, is the foundation of every website. It provides the structure and content of a webpage, acting as a blueprint for what you see in your browser. HTML uses elements, defined by tags, to tell the browser how to display text, images, and other multimedia.

Here's a basic HTML example:

```html
<!DOCTYPE html>
<html>
<head>
  <title>My First Webpage</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>This is a paragraph of text.</p>
</body>
</html>
```

Let's break down the code:

*   **`<!DOCTYPE html>`**: This declaration tells the browser that the document is an HTML5 document.
*   **`<html>`**: The root element of the page; all other elements are nested within this tag.
*   **`<head>`**: Contains meta-information about the HTML document, such as the title, which is not displayed on the page itself.
*   **`<title>`**: Specifies a title for the HTML page, which appears in the browser's title bar or tab.
*   **`<body>`**: Contains the visible content of the page.
*   **`<h1>`**: Defines a level 1 heading, typically the largest heading on the page.
*   **`<p>`**: Defines a paragraph of text.

To see this in action, copy and paste the code into a file named `index.html` and open it in your browser.

## What is CSS?

CSS, or Cascading Style Sheets, controls the presentation and visual styling of your website. It handles aspects like colors, fonts, layout, and responsiveness, separating the design from the HTML content.

Here's how to add some inline styles to our previous example:

```html
<!DOCTYPE html>
<html>
<head>
  <title>My First Webpage</title>
  <style>
    body {
      background-color: #f0f0f0;
      font-family: sans-serif;
    }
    h1 {
      color: blue;
      text-align: center;
    }
    p {
      color: green;
    }
  </style>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>This is a paragraph of text.</p>
</body>
</html>
```

In this example, we've added a `<style>` tag inside the `<head>` section. This is called "internal CSS." Inside the `<style>` tag, we have CSS rules that define the look and feel of different HTML elements:

*   **`body { ... }`**: Styles the entire `<body>` of the page, setting the background color to light gray and changing the font.
*   **`h1 { ... }`**: Styles the `<h1>` heading, making it blue and centering it.
*   **`p { ... }`**: Styles the `<p>` paragraph, setting the text color to green.

Each CSS rule consists of a *selector* (e.g., `body`, `h1`, `p`) and a *declaration block* enclosed in curly braces `{}`. The declaration block contains one or more *declarations*, each specifying a *property* (e.g., `background-color`, `color`, `font-family`) and a *value* (e.g., `#f0f0f0`, `blue`, `sans-serif`).

## Linking External CSS

While internal CSS is suitable for small examples, it's best practice to keep your CSS in a separate file for larger projects. This promotes cleaner HTML and easier maintenance.

Create a new file called `style.css` and add the following CSS rules:

```css
body {
  background-color: #f0f0f0;
  font-family: sans-serif;
}

h1 {
  color: blue;
  text-align: center;
}

p {
  color: green;
}
```

Now, link this CSS file to your HTML:

```html
<!DOCTYPE html>
<html>
<head>
  <title>My First Webpage</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Hello, World!</h1>
  <p>This is a paragraph of text.</p>
</body>
</html>
```

The `<link>` tag in the `<head>` section tells the browser to load the CSS from the `style.css` file. Ensure that `style.css` is in the same directory as your `index.html` file.

## Basic HTML Elements

Here are some other common HTML elements you'll frequently encounter:

*   **`<div>`**: Defines a division or section in an HTML document, often used for grouping elements.
*   **`<span>`**: An inline container used to mark up part of a text or document.
*   **`<a>`**: Defines a hyperlink to another webpage or resource.
*   **`<img>`**: Defines an image to be displayed on the page.
*   **`<ul>`**: Defines an unordered list (bullet points).
*   **`<ol>`**: Defines an ordered list (numbered).
*   **`<li>`**: Defines a list item within an unordered or ordered list.

Example:

```html
<!DOCTYPE html>
<html>
<head>
  <title>More HTML Elements</title>
</head>
<body>
  <div>
    <h1>My Favorite Things</h1>
    <ul>
      <li>Coffee</li>
      <li>Books</li>
      <li>Code</li>
    </ul>
    <a href="https://www.example.com">Visit Example.com</a>
    <img src="image.jpg" alt="My Image">
  </div>
</body>
</html>
```

Remember to replace `image.jpg` with the correct path to your image file. If you don't have an image, you can either leave the `src` attribute empty or use a placeholder image URL.

## Basic CSS Selectors

Besides element selectors (`body`, `h1`, `p`), CSS offers more powerful selectors for targeting specific elements:

*   **Class Selector**: Selects elements with a specific class attribute. Use a dot (`.`) before the class name.
*   **ID Selector**: Selects an element with a specific id attribute. Use a hash (`#`) before the ID name.

Example:

```html
<!DOCTYPE html>
<html>
<head>
  <title>CSS Selectors</title>
  <style>
    .highlight {
      background-color: yellow;
    }

    #main-title {
      color: red;
    }
  </style>
</head>
<body>
  <h1 id="main-title">My Website</h1>
  <p class="highlight">This is a highlighted paragraph.</p>
  <p>This is another paragraph.</p>
</body>
</html>
```

In this example:

*   `.highlight` selects the paragraph with the class `highlight` and sets its background color to yellow.
*   `#main-title` selects the `h1` element with the ID `main-title` and sets its color to red.
